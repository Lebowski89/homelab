# App Changes

## 04.2026

### Done with Discord

Recently, I've removed Discord-focussed apps, including Doplarr and Notifiarr. I realised that I... I just don't like Discord. This was not much of a loss - function-wise, as I use Recyclarr to add custom formats to radarr/sonarr, and Gotify covers notifications.

### Gettin qui with it...

'qui' has been a fantastic addition. Made by those behind autobrr, I knew it would be good, but I didn't anticipate how quickly its functionality would expand within the months after release. It now covers the functionality of cross-seed and qBit-Manage (and more). So while I am thankful for both of those, and wish them the best in the future, I've retired and removed them.
