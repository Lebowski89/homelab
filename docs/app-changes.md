# App Changes

## 04.2026

### Done with Discord

Recently, I've removed apps that are reliant on Discord. This includes Doplarr and Notifiarr. I realised that I... I just don't like Discord, I really don't. This was not much of a loss - function-wise, as I already use Recyclarr to add custom formats to radarr/sonarr, and Gotify covers my notification needs.

### Gettin qui with it...

'qui' has been a fantastic addition to the torrenting community. Made by those behind autobrr, I knew it would be good, but I didn't anticipate how quickly its functionality would expand within the months after release. It now covers the functionality of both cross-seed and qBit-Manage (and more). So while I am thankful for both of those apps, and wish them the best in the future, I've now retired and removed them from my homelab repo.
