# App Changes

## Done with Discord

Over the last few months, I've removed apps that are reliant on Discord. This includes apps like Doplarr and Notifiarr. I came to the realisation that I... I just don't like Discord, I really don't. This was not much of a loss - function-wise, as I was already using Recyclarr to add custom formats to radarr/sonarr, and I deployed Gotify to replace my notification needs.

## Gettin qui with it...

The qui app has been a fantastic addition to the torrenting community. Made by those behind autobrr, I knew it would be good, but I didn't anticipate just how quickly it would progress and how much its functionality would expand within the first few months of release. It now comfortably covers the functionality of both cross-seed and qBit-Manage. So while I am thankful for both of those apps, and wish them the best in the future, I've now retired and removed them from my homelab repo.
